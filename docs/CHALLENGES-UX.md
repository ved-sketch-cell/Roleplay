# Challenges: small actions with a clear finish

The catalogue contains six activities: Say a kind no, Ask before you dive in, One small brave step, Make someone feel heard, Share one useful idea, and Make room for a pause. Filters group them into Boundaries, Connection and Reset. Cards show an outcome, duration and current progress.

The visual system uses a single-column phone layout and a two-column layout from 640px, with larger headings, 14–16px reading text, consistent spacing and 44–50px controls. Each activity has its own gradient SVG illustration, reused in its introduction. Category accents colour the art and labels; purple identifies primary actions and selected filters. Activity footers remain outside the scrolling content. All six illustrations were rendered and visually inspected; the 38 DOM journeys and TypeScript checks pass. Browser and real-device visual verification remains outstanding.

Each activity follows Choose your pace → Prepare → Review → Save plan. Saving is preparation; it does not count as trying the action. The user can mark a plan tried and optionally reflect. Drafts and plans survive navigation and refresh. No invented performance score or XP reward is attached to disclosure or difficulty.

Light and stretch prompts are alternatives, not escalating levels. A boundary exercise practices expressing or respecting a limit; it does not require crossing that limit. Skip, pause and back remain available. Boundary settings open from both the catalogue and activity, then return to the saved draft.

The old daily completion tickboxes and generic poll are removed from this section. Existing quizzes, fact-check practice and Daily Deck remain accessible. Old device keys are retained without being counted as attempts in these new activities.

Possible follow-ups: opt-in partner practice with mutual consent, choosing a specific conversation for a saved response, and an optional reminder chosen by the user. Those require separate implementation; this release sends no messages or reminders.

Anonymous counselling now sits beside the self-guided challenges as a separate support journey. Its teal/purple gradient conversation illustration, topic icons, large radio choices and pinned purple actions share the existing visual language. A three-step request flow captures topic, format, duration, language, timing and an optional short note under the user’s ROLEPLAY alias. Drafts resume; editing preserves the request ID; cancellation retains notes until deletion; delete removes both the request and its note. Replacing a competing draft requires an explicit choice.

This is a device-only planning preview, not live counselling. There are no fabricated counsellor profiles, availability slots, professional replies, appointments or confidentiality guarantees. The user sees the service limit before entering preferences and again before saving. Counselling requests do not count as challenge attempts or earn XP. A real service needs provider onboarding and verification, consent and privacy controls, secure data handling, scheduling, and session infrastructure before these requests can be submitted.
